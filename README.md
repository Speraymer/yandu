# 研读

在浏览器里并排阅读 PDF 原文和中文译文，围绕整篇论文、当前页或选区向 AI 提问。

**[打开研读](https://speraymer.github.io/yandu/)**

## 开始阅读

1. 点「选择 PDF」。文件会加入这台设备上当前浏览器的书架。用同一浏览器配置重新打开链接，会恢复上次阅读的论文和页码。
2. 点「AI 设置」选择DeepSeek 或 OpenAI，填入对应的个人 API Key。可以选择 Easier Paper 循序精读、简明答疑或审稿式质询，也可以写自己的讲解偏好。
3. 点「一键翻译全文」开始逐页翻译。译文会按标题、正文、图注等内容排版，完成的部分会保存。鼠标放在译文或原文上，可看到对应内容高亮，页面保持在当前位置。文字提取依赖 PDF 的文本层，扫描件需要先做 OCR。
4. 划选原文、译文或 AI 回答，可以引用到右栏，也可以新开临时会话。有小窗打开时，选中的 AI 回答还可以添加到已有小窗。发送后，引文随消息保存在对话中，输入框恢复原来的提问范围。引用可在发送前取消，点「定位来源回答」能找回当时选中的句子。
5. 右侧工具栏底部可切换白天与夜间模式。首次打开跟随系统，手动选择后会记住。夜间查看依赖颜色的图表时，点「原色」可单独恢复 PDF 的原始配色。

论文右栏选择「当前页」时显示本页问答，选择「整篇论文」时可以浏览所有主对话。提问可参考同篇论文其他页的相关讨论，临时小窗单独保存。

## 课程学习

要在另一台设备继续学习，在课程页选择「数据包」→「导出当前课程」，将 `.yanduc` 文件拖入另一台设备的课程页。也可以从「数据包」→「导入课程数据包」打开文件。每次导入都会创建独立项目，保留课件顺序、画面和划词位置、每份课件的停留页、学习标记、逐页问答及笔记。API 密钥由各设备单独设置。

从顶部的「课程学习」进入，创建课程项目后可一次导入多份 PPTX 或 PDF。旧版二进制 `.ppt` 可先从 PowerPoint 或 WPS 另存为 PPTX 或 PDF。课件按静态页面显示，复杂图形或特殊字体需要保留原排版时，可导入从 PowerPoint 导出的 PDF。

翻页后直接提问，输入框上方会显示本次提问对应的课件和页码。点击历史问题旁的页码可以返回当时的页面。新导入的页面默认未学。用方向键或在课件画面上滚动即可翻页，翻过的页面自动标为已学。手动设为未学的页面保留该状态。勾选「本页已学」可逐页标记，使用「整份标记」可批量设置。再次使用同一浏览器和站点地址时，课件、标记、问答和阅读位置会自动恢复。

课程问答默认使用 Easier Paper 课件精读，依据当前页和本页最近四组问答讲解。提问涉及其他页或指定课件时可补充同项目材料；询问学习进度时才附上页码标记。每页单独保存对话，回复下方可查看参考过的其他页。OpenAI 可选择附当前页图片，需使用支持图片输入的模型。DeepSeek 使用文字。文件导入和翻页在浏览器本地完成。课程数据存放在本机浏览器，清除站点数据会清空学习记录。

PPTX 静态页使用随站点提供的 [pptx-renderer 1.4.0](https://github.com/aiden0z/pptx-renderer) 和 [html-to-image 1.11.13](https://github.com/bubkoo/html-to-image)。第三方许可证保存在 `course-vendor`。

拖选课件画面中的文字，点「写入笔记」，摘录会随课件名、页码保存。旧课件可点「选择原文件启用划词」，也可把同名原文件拖回当前项目批量补全。页码、学习记录、问答和笔记继续保存在原课件下。展开「本页文字」也可直接选段。图片本身没有文字层的部分无法划词。论文的 PDF 原文和中文译文同样支持划词摘录。

## 换设备继续阅读

在当前论文的「书架」中点「导出当前论文」，把下载的 `.yandu` 文件传到另一台设备。打开研读，点「书架 → 导入阅读包」并选择该文件，即可回到导出时的阅读位置。阅读包自带原始 PDF、已译内容、双语视图、笔记、右栏和临时会话记录。收到文件的人可以读取这些内容。模型密钥留在各自设备。

同一份 PDF 重复导入时，书架和问答按记录去重，已完成的译文优先保留，两端不同的笔记会合并。阅读包保存导出时的进度，后续阅读可再次导出。

## 数据与隐私

| 操作 | 数据去向 |
| --- | --- |
| 打开 PDF、翻页、写笔记 | 浏览器使用 IndexedDB 和 localStorage 保存 PDF、页码、译文、笔记、对话和偏好。网站不设账户。 |
| 翻译 | 浏览器把待译文本分批发给所选模型服务商。已存储的译文可以直接阅读。 |
| 向 AI 提问 | 所选范围的论文文字、问题、阅读偏好和最近的对话会直接发给所选服务商。选择「整篇论文」时会发送全文可提取的文字。 |
| 填写密钥 | 默认仅当前标签页有效。在私人设备勾选「在此浏览器记住密钥」并点「应用设置」，重开后即可继续使用。各服务商的密钥分别保存，可在「AI 设置」选中服务商后点「忘记此密钥」。请求计入读者自己的模型账户。 |

每个人的书架属于所用浏览器的配置文件。选择记住的密钥通过 Web Crypto 加密，密文和不可导出的解密密钥都由此浏览器保存在 IndexedDB。能使用同一浏览器配置的人或能在同一源运行的脚本仍可调用这些密钥，共用电脑请使用默认选项。跨设备或浏览器迁移单篇论文时可使用阅读包。无痕窗口结束、清理站点数据或浏览器回收存储空间都可能清空记录，请保留重要 PDF 的原文件。

## 运行与部署

项目为静态 HTML、CSS 和 JavaScript。克隆后在仓库根目录运行以下命令，然后打开 <http://127.0.0.1:8000/>。

```sh
python serve.py
```

在 GitHub 仓库的 **Settings → Pages** 中选择 **Deploy from a branch → main → / (root)** 并保存。自托管时请使用 HTTPS 或 localhost，并长期保留同一站点地址。

运行模型请求和原译文对齐检查需要 Node.js 22 或更高版本。

```sh
node --test tests/*.test.mjs
```
